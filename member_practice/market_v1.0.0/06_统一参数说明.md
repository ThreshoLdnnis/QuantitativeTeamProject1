# 统一参数说明

适用分发版本：`QTP1-MARKET-FILES-1.0.0`。机器读取的参数文件是 `market_teaching.json`，与原教学包保持相同字节；本文解释字段，并补充原项目已经采用的共同实现口径。比较基线时三人使用相同数据、参数和规则，探索实验另行命名并保存。

## 1. 先区分输入历史和正式评价

| 参数 | 固定值 | 含义 |
| --- | --- | --- |
| `start` | `2023-01-01` | 正式评价起始边界，实际交易日期以日历为准 |
| `end` | `2025-12-31` | 正式评价结束边界 |
| `splits.development` | 2023 全年 | 开发段，用于理解、实现和检查方案 |
| `splits.validation` | 2024 全年 | 验证段，用于比较固定方案的表现 |
| `splits.test` | 2025 全年 | 测试分区，用于统一报告基线表现 |

三份 CSV 保存 2019–2025 年的历史，不能直接把全部历史绩效都当成本次正式结果。计算 2023 年初的因子可以使用之前已发生的行情作预热，不能读取信号日之后的价格。本次是已经看过教学方案后的独立复现，2025 年不能再被描述为从未查看过的全新样本外试验。

## 2. 三个因子怎样定义

全部按独立交易日历对齐，每只股票分别按日期升序计算。窗口是交易日格子数，缺失格子保留；不能删除缺行情后把“向后 20 行”当作“向后 20 个交易日”。

| 参数 | 固定值 |
| --- | --- |
| `lookback` | 20 |
| `activity_short` | 5 |
| `activity_long` | 20 |
| `activity_mode` | `relative_volume` |
| `directions` | 动量 `+1`；波动率 `-1`；活跃度 `-1` |

设 `P_t` 为当日复权收盘价，`V_t` 为当日成交量：

- **20 日动量：**`P_t / P_(t-20) - 1`。需要包含当日的连续 21 个有效价格。窗口内缺失时动量为空，不能只检查两个端点。方向为正，原始动量越高越倾向于获得高分。
- **20 日波动率：**先计算 `r_t = P_t / P_(t-1) - 1`，再对最近 20 个有效日收益求样本标准差，即 `ddof=1`。这里是日频波动率，因子本身不乘年化系数。方向为负，波动率越低越倾向于获得高分。
- **5/20 相对成交量：**最近 5 个交易日成交量均值 ÷ 最近 20 个交易日成交量均值。长窗口均值须大于零，窗口不足或缺失保留为空。本版不改用换手率。方向为负，较低相对活跃度倾向于获得高分；这是事先规定的教学研究方向，不能看完收益后临时翻转。

三个因子先保留原始值，按当日 `eligible=1` 的股票形成截面。零值和缺失值不同，不能把没有足够历史的因子补成零。

## 3. 去极值、标准化和合成

`mad_scale=3.0`，原项目采用的具体顺序是：

1. 原始因子先乘对应方向 `+1/-1`。
2. 在同一天的有效股票中，取中位数 `m`，计算 `MAD = median(|x-m|)`；若 MAD 大于零，将数值裁剪到 `m ± 3 × 1.4826 × MAD`。MAD 为零时跳过去极值。
3. 对裁剪后的截面做标准化：`z = (x-均值)/总体标准差`，这里截面标准差用 `ddof=0`。
4. 三个方向分数全部有效时，合成分数为 `(z_momentum + z_volatility + z_activity) / 3`；任何一个缺失，合成分数为空。

少于两个有效值时无法估计截面离散程度，分数保留为空；有效截面为常数或达到数值上近似常数时，分数取零。不要把“20 日收益的样本标准差”和“当日截面标准化的总体标准差”混成一个口径。

`groups=5` 表示因子检验按分数分为五组，比较低分到高分的理论未来收益；不代表实际账户同时持有五个组合。

## 4. 选股、调仓和基准

| 参数 | 固定值 | 用途 |
| --- | --- | --- |
| `top_n` | 10 | 选择综合分数最高的目标股票数量上限 |
| `initial_cash` | 1,000,000 元 | 初始资金 |
| `groups` | 5 | 因子评价组数 |

原项目共同规则如下，它们不是 JSON 中单独列出的所有字段，但会影响复现结果：

- 每个月最后一个交易日收盘后，用截至当天已经发生的信息计算分数；有下一交易日时才形成可执行月末信号。
- 下一交易日开盘尝试调仓，使用 `adj_open` 作为执行代理并计入滑点；不能用已经计算完信号的当日收盘价成交。
- 综合分数降序选择最多 10 只，分数相同按股票代码升序；仅使用三个分数完整的合格股票。
- 目标为等权，按调仓前开盘权益计算目标数量；先卖出减仓部分，再按可负担现金执行买入。可分割持仓单位是复权价格下的经济份额代理，不是交易所实际股数。
- 卖不出则保留持仓，买不进则保留现金；未成交订单当日失效，不在次日自动补单。买卖受限不应先拿来改变信号排名。
- 每日按复权收盘价估值；已持仓缺少有效估值时应停止并报告，不能隐式前向填价或填零收益。期末按最后收盘价估值，不额外假定全部清仓。
- 基准是在每个月相同的因子完整合格集合上等权配置的教学池组合，也经过共同成交、费用和现金核算；不是自动等于沪深 300，也不是直接平均所有日收益。

真实输入全部 `status_known=0`。为了复现许可未知状态执行的教学基线，需要在运行参数中显式增加并记录 `allow_unknown_status=True` 或等价开关，原 `market_teaching.json` 不含该字段。它不能被默认为历史可成交性已验证，也不能通过改原始数据或覆盖冻结 JSON 来实现。选择拒绝未知状态的结果要单独说明，不能直接与许可执行基线比较。

## 5. 费用怎样计算

`1 bps = 0.0001 = 0.01%`。

| 参数 | 固定值 | 基线含义 |
| --- | --- | --- |
| `commission_bps` | 3 | 每笔买入、卖出成交额的 0.03% 佣金 |
| `slippage_bps` | 5 | 买价上浮 0.05%，卖价下浮 0.05% 的滑点代理 |
| `sell_tax_bps` | 5 | 卖出成交额的 0.05% 教学税费假设 |
| `cost_multipliers` | `[0,1,2]` | 将上述三种成本同时乘 0、1、2，做成本敏感性比较 |
| `annual_risk_free` | 0 | 计算相关风险调整指标时采用的年化无风险利率假设 |

佣金、税费按实际执行成交额计算，滑点已经进入执行价，权益核算不能再重复扣一次滑点。成本记录可以同时展示滑点影响，但不能把展示字段误当成第二次扣款。

这些是统一教学成本假设，没有按每个历史日期、账户、最低佣金和真实交易制度逐笔复原。不能把 3 bps 写成 3%，也不能只把佣金加倍而把其他成本保持不变。

## 6. 因子评价与回测要分别解释

因子 IC 和五分组使用“下一交易日复权开盘价 → 下一次月度调仓执行日复权开盘价”的理论未来收益。没有完整入场、离场报价或跨开发／验证／测试边界的标签不用于对应评价；未来收益只用于检验，不能加入当期信号。

理论标签是未扣成本的诊断口径，不通过买卖标记筛选成“保证能成交的收益”。实际策略回测另行处理现金、持仓、费用及受限订单。因此 IC、组收益和实际账户净值是相关但不同的输出。

绩效分区从同一连续策略的区间日收益计算，不能每进入新分区就重置资金和重新建仓。最终报告要同时给出各区间表现、有效样本数量、成本敏感性和数据局限。

JSON 冻结的是参数值，并未编码所有排名、缺失值、标签、交易和会计规则。三人的实现还须遵循本文及任务要求，遇到未约定的问题由负责人统一明确并留下版本记录，不能各自猜一种规则后只比较最终收益。
