# 数据字典

日期统一为 `YYYY-MM-DD`，内部计算转为 pandas 日期；股票代码始终保留为字符串。不能把 `000001` 读成整数 `1`。行情按 `symbol,date` 排序，日历日期不重复。

## 输入目录

```text
prices.csv       逐股逐日行情与执行状态
universe.csv     逐日股票池资格
calendar.csv     独立交易日历
metadata.json    来源、下载与研究范围说明
raw/             真实数据原始响应的本地留存
```

真实数据适配器分别获取原始与后复权（hfq）行情；复权开盘、收盘是研究用连续价格代理，原始 OHLC 保留供核查。后复权价格不等于当时实际交易报价。模拟数据的价格与状态均由程序生成。

### prices.csv / SQLite stock_prices

主键为 `(date,symbol)`，不应自动“保留最后一条”掩盖冲突记录。

| 字段 | 类型 / 单位 | 用途与约束 |
| --- | --- | --- |
| `date` | 日期 | 必须属于输入交易日历 |
| `symbol` | 字符串 | 股票标识；保留前导零 |
| `open` | 正数，元 | 未复权开盘价 |
| `high` | 正数，元 | 未复权最高价，应不低于开收盘 |
| `low` | 正数，元 | 未复权最低价，应不高于开收盘 |
| `close` | 正数，元 | 未复权收盘价 |
| `adj_open` | 正数，复权价格单位 | 理论标签和回测开盘执行代理 |
| `adj_close` | 正数，复权价格单位 | 收益、因子与收盘估值代理 |
| `volume` | 非负数，股 | 标准化成交量；AKShare 原始“手”乘以 100 转为股，原始快照保留源单位 |
| `turnover` | 比例，可缺失 | 换手率；`0.02` 表示 2%，不是 `2` |
| `can_buy` | 0/1 | 当日执行时买入是否允许；不是当日是否有过成交 |
| `can_sell` | 0/1 | 当日执行时卖出是否允许 |
| `status_known` | 0/1 | 上述执行状态是否经过可靠历史数据确认 |

`can_buy=True` 但 `status_known=False` 表示教学默认假设，不表示真实历史保证可成交。`volume=0`、缺失行情、停牌和退市是不同事件，不能互相替代。仅凭日线数据也不能完整重建开盘盘口。

### universe.csv / SQLite stock_universe

| 字段 | 类型 | 含义 |
| --- | --- | --- |
| `date` | 日期 | 资格生效的交易日 |
| `symbol` | 字符串 | 股票标识 |
| `eligible` | 0/1 | 在该日信号形成时是否属于研究股票池 |

主键 `(date,symbol)`。历史股票池应由当时有效的成员信息生成；将现在的一组股票复制到所有历史日期，只能称为固定教学股票池。成员资格缺失不能自动推断为已知合格。

### calendar.csv / SQLite trading_calendar

只有 `date` 一列，表示全市场研究交易日。日历决定滚动窗口、月末信号与下一交易日。不能用“下一自然日”代替下一交易日；也不能由单只停牌股票的行情日期独自决定市场日历。

## 派生表

### factors.csv / SQLite factor_values

| 字段 | 含义 |
| --- | --- |
| `date,symbol` | 因子截面的主键 |
| `momentum` | 20 日复权累计收益，比例 |
| `volatility` | 20 日收益样本标准差，日频，未年化 |
| `activity` | 20 日平均换手率，或 5/20 相对成交量；由配置统一指定 |
| `z_momentum,z_volatility,z_activity` | 去极值、截面标准化并乘以预设方向后的分数 |
| `composite` | 三个有效方向分数的等权平均 |

空值可能表示预热不足、缺失交易日、当前不合格或因子无效。零分和空值含义不同。

### labels.csv

逐只股票保存信号日期、下一交易日入场日期、下一调仓执行日离场日期、理论未来收益和样本分区。未来收益为复权开盘到复权开盘的价格比减一，没有完整期限或跨分区边界的记录不进入有效性统计。

### ic.csv、ic_summary.csv

`ic.csv` 按信号日、因子、分区记录 IC 和有效股票数；`ic_summary.csv` 汇总有效期数、平均 IC、IC 标准差和未年化 ICIR。若有 HAC t 统计量，只作探索性统计量。缺失 IC 不应补零后再计算平均数。

### groups.csv、correlation.csv

分组表按信号日、因子、组别、分区保存平均理论未来收益及股票数，组别由低分到高分。相关性表用于检查因子信息重复，不等于因子具有预测能力。具体有效样本数应随解释一起保留。

### daily_*.csv

| 字段 | 含义 |
| --- | --- |
| `date` | 交易日 |
| `nav` | 累计净值，初始资金对应 1 |
| `cash` | 收盘后现金，元 |
| `equity` | 现金与持仓收盘市值之和，元 |
| `return` | 相对上一日权益的收益率，首日相对初始资金 |
| `turnover` | 当日买卖成交额合计 / 调仓前权益 |
| `cost` | 当日佣金、税费与滑点成本统计，元 |
| `holdings_count` | 实际持有股票数量 |

### trades_*.csv、orders_*.csv

成交表包含执行日、信号日、股票、方向、数量、执行价格、成交额及成本明细。数量使用复权价格单位下的可分割持仓单位，不可直接当作真实股数。

订单表记录实际处理结果及拒单原因。目标名单、发出订单、成功成交是三层不同的信息；不应只保存成功成交而删去受限订单。

### positions_*.csv / SQLite portfolio_positions

| 字段 | 含义 |
| --- | --- |
| `date,symbol` | 持仓日期和股票 |
| `quantity` | 实际持仓单位 |
| `close` | 当日估值使用的复权收盘价 |
| `market_value` | 数量乘估值价格 |
| `weight` | 该市值 / 当日权益 |
| `strategy` | 仅数据库合并多种策略时增加；单策略 `positions_*.csv` 由文件名区分 |

### metrics.csv 与运行记录

`metrics.csv` 保存策略与成本情景的收益和风险指标；`relative_return` 是 `(1+策略收益)/(1+基准收益)-1`。分区指标使用同一连续策略的区间日收益，保留首日相对上一个交易日的收益起点，不是在每个区间重新建仓。`config_snapshot.json` 保存本次参数，`manifest.json` 记录运行与可复现信息，`data_quality.json` 保存数据质量检查。

读取结果时先看 `metadata.json` 与报告中的模拟/真实标记，再看绩效数字。换了数据、股票池或参数，应生成独立运行目录。

附带 `data/market_teaching` 为真实固定教学池，2019-2025 年 30 只股票、50,927 行。全历史缺口为 37，`configs/market_teaching.json` 的正式评价范围为观测覆盖完整的 2023-2025 年；`data_quality.json` 仍记录输入全范围的缺口，不应误读为该评价段仍有同样缺口。历史可成交状态为未知，需单独披露。
