## 2. 创建独立 Python 环境

项目使用 Python 3.11 及以上版本，本次教学按 Python 3.12 验证。`.venv` 是当前项目的独立环境；解压交付包后需要在本机创建，不从其他机器复制虚拟环境。

先选一个本机确实可用的解释器。以下三种方式只选择一种：

```powershell
# 本机有 Python Launcher 时
py -3.12 -m venv .venv
```

```powershell
# 没有 py，但安装的 Python 提供了 python3.12 命令时
python3.12 -m venv .venv
```

```powershell
# 或使用本机真实 Python 安装位置；把示例路径换成自己的路径
& 'C:\实际的Python安装目录\python.exe' -m venv .venv
```

已有正常 `.venv` 时，可以直接使用，不必重复创建。后续统一使用下面这个解释器，无需执行激活脚本：

```powershell
.\.venv\Scripts\python.exe --version
.\.venv\Scripts\python.exe -c "import sys; print(sys.executable)"
```

第二条输出应指向本项目 `.venv\Scripts\python.exe`。Windows 应用商店的 `python.exe` 别名不等于已经安装好的真实解释器。

安装当前教学版本的依赖和项目：

```powershell
.\.venv\Scripts\python.exe -m pip install -r requirements-tested.txt -e ".[plots]"
```

这里 `-m pip` 表示让指定的 Python 运行 pip；`-r` 读取已验证依赖版本；`-e` 将当前项目作为开发项目安装；末尾的 `.` 是当前项目目录。`[plots]` 安装课堂绘图所需的 Matplotlib。NumPy 负责数值计算，pandas 负责表格与时间序列处理。

模拟演示和复现已有真实快照都不需要 AKShare。只有重新联网下载行情时才需要可选的 `market` 依赖；本指南不重新下载。

## 3. 准备所有模拟课程的固定输入

第 01-17 课脚本固定读取 `runs/first_demo_20261107/input`。这个名字虽然带日期，也是当前课堂约定的输入位置；不能只生成 `runs/my_demo` 后直接期待这些脚本能找到数据。

交付包已包含现成输入。如果要从头生成相同的模拟样本，在项目根目录运行：

```powershell
.\.venv\Scripts\python.exe -m ashare_lab demo --config configs/baseline.json --out runs/first_demo_20261107 --seed 20261102
```

命令使用固定随机种子生成 40 只人工股票，再完成一次完整研究流水线。输入包含 2019 年预热数据，正式评价期为 2020-2025 年。它会写入该目录的输入及实验成果；需要保留我自己修改过的实验时，先另存一份。

模拟日历使用工作日，包含中国节假日；它不是 A 股真实交易日历。人工成交量允许小数，人工状态用于演示受限成交。模拟绩效不证明真实市场因子有效。

熟悉每一步以后，也可以用 PowerShell 按顺序执行 01-18；任何一课失败都会停止：

```powershell
$lessonFiles = Get-ChildItem -LiteralPath '.\examples' -Filter '*.py' |
    Where-Object { $_.Name -match '^(0[1-9]|1[0-8])_' } |
    Sort-Object Name
foreach ($lessonFile in $lessonFiles) {
    & '.\.venv\Scripts\python.exe' $lessonFile.FullName
    if ($LASTEXITCODE -ne 0) {
        throw "课程运行失败：$($lessonFile.Name)"
    }
}
```

## 7. 验收：能运行，也能解释

工程检查：

1. 本机解释器位于 `.venv`，依赖安装成功；测试日志以 `OK` 结束。
2. 模拟输入为 40 股、73,080 行；01-18 能按顺序运行，关键账户恒等式和来源核对通过。
3. 第 18 课报告路径正确；真实快照输入哈希保持一致，正式研究区间合格行情缺口为 0。
4. 第 19 课校验记录通过，总览、清单和 ZIP 对应同一批文件；解压后内部相对链接仍有效。

口头或手算解释题：

- 为什么 20 日动量要用 21 个收盘价？为什么不能把不同股票的记录直接 `shift`？
- 原始价格与复权价格、因子与未来标签、目标持仓与实际持仓分别有何区别？
- 月末收盘形成信号后，为什么从下一交易日开盘开始执行和计算检验收益？
- IC=0.1 表示什么？它为什么不等于 10% 收益或 10% 胜率？
- 卖不出旧持仓时，现金、新买入规模和实际权重会怎样变化？
- 如何从“上一日权益 → 开盘旧持仓 → 买卖和成本 → 收盘市值”复算一天的净值？
- 为什么把每段净值重设为 1，不等于在每段重新从现金建仓？
- 为什么真实区间覆盖完整，仍不能说历史订单必然能成交？

更多题目见 [答辩与自查](04_答辩与自查.md)。示例通过和自动测试通过，只证明覆盖到的实现行为符合当前定义，不能替代我亲手解释。

## 8. 剩余研究边界

- 模拟部分用于验证工程和学习，不产生 A 股有效性结论。真实部分是 30 股手工固定幸存样本，存在选择和幸存者偏差，不代表全 A 股或历史指数成分。
- 原始真实快照为 2019-2025 年 50,927 行、1,699 个交易日。完整固定网格缺 43 行，其中合格成员缺 37 行；首条观测前被标记不合格的 6 行，不能据此认定股票尚未上市。
- 2020-2025 年真实尝试曾因持仓 `600009` 在 2021-06-10 缺价而停止；记录保留，未完成该完整区间的真实实证。2023-2025 年是在查看策略绩效前按行情完整性冻结的教学区间。
- 真实 `can_buy/can_sell` 仅由成交量大于 0 构造，全部历史 `status_known=False`；并非已核实的历史涨跌停、ST、停复牌或开盘可成交状态。
- 引擎使用后复权价格与可分割持仓单位，未完整模拟原始股数、企业行动现金流、整手、最低佣金、容量冲击、退市结算和历年税费变化。期末按最后收盘价估值，没有假设强制清仓并收费。
- 因子 IC、分组收益是理论未来标签检验；账户净值另行模拟费用与已提供的成交约束。二者口径不同，不能把理论分组差直接说成可实现净收益。
- 同一数据和测试期已经被查看；教学复现不构成新的独立检验。小样本、重复研究和未进行的行业/市值中性化仍限制结论。
- 完整论文仍需核实原始文献、解释真实实验结果、明确统计证据及研究范围。完成这 19 课形成可运行的参考工程，不自动等于完成所有实证条件或证明因子有效。

研究公式与更完整边界见 [研究设计](02_研究设计与边界.md)，字段见 [数据字典](03_数据字典.md)，最初构建记录见 [本次构建与验证](05_本次构建与验证.md)。
