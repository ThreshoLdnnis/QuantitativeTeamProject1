## 先认识六个对象

| 对象 | 在本项目中的含义 | 最容易混淆的地方 |
| --- | --- | --- |
| 行情 | 每只股票每个交易日的价格、成交量 | 原始价格与复权价格用途不同 |
| 因子 | 在某时点用已知数据算出的股票特征 | 因子不是未来收益，也不保证有效 |
| 标签 | 从信号之后开始计算的未来收益 | 标签只用于事后检验，不参与当时选股 |
| 股票池 | 当时允许被研究和选入的股票集合 | 今天的成分股不能冒充历史成分股 |
| 持仓 | 实际模拟成交后仍持有的资产 | 目标持仓不一定全部成交 |
| 净值 | 现金加持仓市值，除以初始资金 | 不能只对选中股票收益简单平均 |

## 接入真实数据

先使用已附带数据运行：

```powershell
python -m ashare_lab run --data data/market_teaching --config configs/market_teaching.json --out runs/market_teaching --allow-unknown-status
```

该配置研究 2023-2025 年，按 2023 开发、2024 验证、2025 测试划分。附带数据的下载范围是 2019-2025 年，共 30 只股票、50,927 行；全历史存在 37 个合格股票/交易日的缺口。原定 2020-2025 年真实回测因持仓 `600009` 在 `2021-06-10` 缺少价格而主动停止，没有静默填价或删股。缩至 2023-2025 年是观察策略绩效前做的数据完整性选择，30 只股票在该段的观测行情覆盖完整；详情见 `05_本次构建与验证.md`。这不等于其历史可成交状态已经完整。

需要学习下载或创建新快照时，先少量取数，确认网络、字段和时间区间正确，再扩大股票池。下面三个代码仅测试接口，数量不足以开展可信的五分组研究，也不是投资推荐。

```powershell
python -m pip install -e ".[market]"
python -m ashare_lab fetch --symbols 000001,000002,600000 --start 20190101 --end 20251231 --out data/market
python -m ashare_lab run --data data/market --config configs/market_teaching.json --out runs/market_sample --allow-unknown-status
```

`--allow-unknown-status` 表示我明确接受“历史可成交状态不完整”的教学假设。该命令不会补出真实的历史涨跌停、ST、停复牌或退市信息。可靠的 `can_buy/can_sell` 可由我另行准备后导入；不能用当天最终收盘价推断当天开盘一定能够成交。

当前真实股票池由现在仍可获取的 30 只股票固定回溯，存在幸存者与选择偏差；它不是历史指数成分，也不能代表全 A 股。

真实数据阶段依次检查：原始和复权数据是否对齐；日历是否来自可靠交易日历；股票池成员是否可追溯；缺失日期是否与停牌有关；下载失败是否造成样本缩水。先下载成功再讨论因子效果。

## 每一步怎样验收

- 数据：日期、代码、数值单位一致；主键不重复；价格合法；缺失有解释；保存下载时间与来源。
- 因子：只用信号日及之前的数据；滚动窗口以交易日计；样本不足留空；手算结果一致。
- 检验：未来收益从下一交易日开盘起算；IC 保留有效样本数；跨样本分界的收益标签被剔除。
- 选股：方向、权重、选股数量在最终测试前固定；并列分数按代码稳定排序。
- 回测：不能按信号日收盘成交；实际持仓、现金和成本能够逐笔对上；拒单留记录。
- 报告：每个数字能追溯到一次运行；模拟数据与真实数据结论分开；无效或不稳定结果照实写。

## 遇到问题时

| 现象 | 先检查什么 |
| --- | --- |
| `python` 不可用或指向应用商店 | 使用实际 Python 安装路径或虚拟环境解释器 |
| 找不到 `ashare_lab` | 是否在项目根目录执行过 `pip install -e .` |
| 行情下载失败 | 先只取一只股票；检查网络和 AKShare 版本，保留异常；不要静默跳过 |
| 全部因子为空 | 是否包含至少 21 个历史收盘价；是否混入字符串或存在缺失交易日 |
| IC 为空 | 是否有完整未来持有区间；横截面股票数是否足够；分数是否全相同 |
| 换手很高、净收益差 | 检查选股稳定性、费用口径与策略实际持仓，不先改测试集参数 |
| 报告很好看却无法解释 | 回到一个信号日、一只股票、一笔交易，把时间与资金算清楚 |
