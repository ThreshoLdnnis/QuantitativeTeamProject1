# 答辩、自查与完成标准

每题先口述，再用一小段数据或一笔交易证明。参考答案只规定关键点，不要求背诵。

## 我应能独立回答的 15 题

| 问题 | 回答中必须包含 |
| --- | --- |
| 1. 因子、标签、持仓分别是什么？ | 因子当时已知；标签事后可知；持仓取决于实际成交 |
| 2. 为什么动量窗口 20 需要 21 个收盘价？ | 比较 t 与 t-20，包含 20 段日收益 |
| 3. 20 日收益波动率怎么手算？ | 日收益序列、样本标准差、`ddof=1`、未年化 |
| 4. 相对成交量为什么比绝对量更适合这版比较？ | 各股短长均量之比；降低规模单位影响；不等于真实换手率 |
| 5. MAD 与 z-score 各解决什么问题？ | 减少极端值影响；统一截面尺度；都不创造预测能力 |
| 6. 为什么先统一因子方向？ | 高分始终代表更愿意买；方向是假设、开发期确定 |
| 7. IC=0.1 是什么意思？ | 截面秩相关；不是 10% 收益、胜率或解释度 |
| 8. ICIR 很高就能交易吗？ | 仍需样本数、稳定性、费用、可成交性与偏差检查 |
| 9. 为什么不按当天收盘价买入？ | 完整收盘数据形成信号时，当天收盘成交机会已过去 |
| 10. 为什么标签是下一开盘到再下一调仓开盘？ | 与执行起点对齐，不能把已发生的信号日收益算进去 |
| 11. 卖不出旧持仓会发生什么？ | 股票仍持有，资金未释放，买入受现金约束，保留拒单 |
| 12. 为什么今天的股票池不能直接倒推历史？ | 退市和被剔除股票缺失；幸存者与选择偏差 |
| 13. 为什么不能随机划分时间序列？ | 未来环境进入开发，收益标签可能跨边界 |
| 14. 复权价回测与真实现金账有什么差异？ | 连续收益代理、分割单位；未完整记账真实分红、股数和整手 |
| 15. 测试集结果不好，接下来怎么办？ | 如实报告；提出新假设并寻找新样本，不能反复调到同一测试集变好 |

## 两张必须亲手算出的表

表 A：选一只股票的连续 21 个有效收盘价，写出最近一期动量、20 个日收益、波动率；在一个截面写出中位数、MAD、去极值和方向分数。

表 B：选第一次与第二次调仓，逐项写出调仓前现金、旧持仓开盘市值、卖出收入、买入支出、佣金税费、收盘市值和最终净值。检查 `cash + sum(market_value) = equity`，并解释为何实际权重可能偏离目标等权。
